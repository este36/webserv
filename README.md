# webserv

## Instructions

Compiler :

```sh
make
```

Rebuild complet :

```sh
make re
```

Lancer les tests :

```sh
make run_tests
```

Check du formatage :

```sh
make lint
```

Fix automatique du formatage :

```sh
make fix-lint
```

Voir [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md) pour plus de détails.
